# backend

Generated by `prisma orm init` with the Minimal template.

## First run

1. `yarn run db:up` — start the local MongoDB replica set with `mongodb-memory-server`. Data persists in `.mongo-data/` across restarts.
2. `yarn run dev` — runs `src/index.ts`, which writes one row and reads it back.

## Available scripts

- `yarn run dev` — run the Prisma ORM sample script

### Database and migrations

- `yarn run contract:emit` — emit contract artifacts after contract changes
- `yarn run db:up` — start the local MongoDB replica set with `mongodb-memory-server`. Data persists in `.mongo-data/` across restarts.
- `yarn run db:down` — stop the local MongoDB process (data preserved)
- `yarn run db:reset` — stop and wipe `.mongo-data/` for a clean slate
- `yarn run migration:plan` — create a MongoDB migration plan
- `yarn run migrate` — apply the planned MongoDB migration
- `yarn run db:seed` — insert sample users manually

## Prisma ORM

Prisma ORM setup is scaffolded in:

- `src/prisma/contract.ts`
- `prisma.config.ts`
- `prisma/db.ts`
- `src/lib/prisma.ts`

For provider-specific Prisma ORM reference docs, see `prisma-8.md`. Prisma ORM skills live in the upstream `skills/` directory: https://github.com/prisma/prisma/tree/main/skills.

Node-based Prisma ORM projects expect Node.js 24 LTS or newer.
